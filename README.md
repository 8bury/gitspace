# GitSpace

GitSpace é um projeto para transformar um perfil do GitHub em um sistema solar interativo.

## Ideia

- Estrela central = perfil do GitHub
- Cor da estrela = linguagem mais usada recentemente
- Cada repositório = um planeta
- Tamanho do planeta cresce com commits
- Stars influenciam o tipo do planeta:
  - muitos commits + poucas stars → sólido, médio
  - poucos commits + muitas stars → gasoso, grande
  - muitas stars → planeta com anel
- Cor do planeta = linguagens principais do repositório
- Assinatura visual por linguagem (cor + textura/estilo)
- Card de share para gerar imagem pronta e postar
